# AIVO 기능 명세서 — 간단 버전

우선순위는 `상`(핵심 기능), `중`(완성도 향상), `하`(추후 확장)으로 구분한다.

## 유저

| 기능명 | 기능 설명 | 우선순위 |
|---|---|---|
| 회원가입 | 이메일과 비밀번호를 이용해 계정을 생성한다. | 상 |
| 로그인·로그아웃 | 계정으로 로그인하거나 현재 접속을 종료한다. | 상 |
| 회원 정보 조회·수정 | 이름, 이메일 등 기본 회원 정보를 확인하고 수정한다. | 중 |
| 비밀번호 변경 | 기존 비밀번호 확인 후 새로운 비밀번호로 변경한다. | 중 |
| 회원 탈퇴 | 계정과 저장된 사용자 데이터를 삭제한다. | 중 |
| 이력서·포트폴리오 관리 | 면접 연습에 사용할 지원 자료를 등록·조회·변경한다. | 중 |

> 유저 기능은 서비스 구현 예정 범위이며 현재 프로토타입에는 계정 기능이 연결되어 있지 않다.

## 공통

| 기능명 | 기능 설명 | 우선순위 |
|---|---|---|
| 홈 대시보드 | 누적 연습 지표와 최근 연습 기록을 확인한다. | 상 |
| 연습 유형 선택 | 발표 연습과 면접 연습 중 원하는 모드를 선택한다. | 상 |
| 연습 폴더 선택 | 새 폴더를 만들거나 기존 폴더에서 다음 시도를 시작한다. | 상 |
| 공통 연습 설정 | 연습명, 목표 말하기 속도, 습관어를 설정한다. | 상 |
| 카메라·마이크 녹화 | 장치 권한을 허용하고 영상과 음성을 녹화한다. | 상 |
| 녹화 제어 | 녹화를 시작하고 일시 정지·재개·종료한다. | 상 |
| 실시간 음성 인식 | 발화를 텍스트로 변환하고 말하기 속도와 습관어를 표시한다. | 상 |
| 녹화 영상 재생 | 리포트에서 저장된 영상을 재생하고 원하는 구간으로 이동한다. | 상 |

## 발표

| 기능명 | 기능 설명 | 우선순위 |
|---|---|---|
| 발표 자료 등록 | PDF 또는 PPTX 자료를 업로드하고 슬라이드 미리보기를 생성한다. | 상 |
| 발표 목표 설정 | 목표 발표 시간과 집중해서 받을 피드백을 입력한다. | 상 |
| 슬라이드 핵심 내용 설정 | 슬라이드별 핵심 내용을 작성하거나 자동 초안을 생성한다. | 상 |
| 분석 제외 설정 | 설명하지 않을 슬라이드를 분석 대상에서 제외한다. | 중 |
| 슬라이드 발표 녹화 | 자료를 넘기며 발표 영상·음성과 슬라이드별 시간을 기록한다. | 상 |
| 슬라이드별 발화 연결 | 실시간 발화문을 당시 표시 중인 슬라이드와 연결한다. | 상 |
| 청중 질문 연습 | 발표 내용에 대한 가상 청중 질문에 음성 또는 텍스트로 답한다. | 상 |
| 발표 시간 분석 | 슬라이드별 발표 시간과 전체 발표 비율을 타임라인으로 제공한다. | 상 |
| 내용 적절성 평가 | 슬라이드 핵심 내용과 실제 발화의 일치 여부를 평가한다. | 상 |
| 전달·비언어 평가 | 말하기 속도, 습관어, 시선·자세 등 전달 방식을 평가한다. | 상 |
| 청중 답변 평가 | 청중 질문 답변의 명확성, 관련성, 구조를 평가한다. | 상 |
| 문제 구간 확인 | 문제가 발생한 슬라이드의 녹화 구간을 바로 재생한다. | 상 |
| 통합 발표 리포트 | 발표 내용, 전달 방식, 청중 답변 결과를 한 화면에서 제공한다. | 상 |
| 발표 다시 연습 | 같은 자료와 설정으로 새로운 발표 시도를 시작한다. | 중 |

## 참고 사항

- 카메라, 마이크, 음성 인식 기능은 브라우저 지원과 사용자 권한 허용이 필요하다.
- 발표 시선·자세는 MediaPipe, 음량은 Web Audio로 실제 측정한다. 내용 의미 평가·질문 생성·답변 평가와 면접 분석은 아직 목/규칙 기반이며 AI API 연동이 필요하다.
- 발표·면접 녹화는 서버 API 업로드를 우선 시도하고 미연결 시 로컬 폴백으로 진행한다. 폴백은 녹화 Blob을 영속 저장하지 않으며, 아카이브 기록은 API 미연결 시 LocalStorage 시드 데이터로 대체한다.
