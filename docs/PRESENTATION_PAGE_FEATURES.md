# AIVO 발표 코칭 기능 명세서

## 1. 문서 개요

- 대상 구현: `src/views/presentation/*` (Vue 3 SFC), 상태 `src/stores/presentationStore.js`, 로직 `src/composables/*`
- 대상 범위: 발표 연습 기능
- 제외 범위: 면접 연습 기능
- 사용자 흐름: `홈 → 발표 연습 선택 → 연습 폴더 선택 → 발표 준비 → 슬라이드 핵심 내용 설정 → 발표 녹화 → 청중 질문 답변 → 통합 리포트 → 비교·재연습·아카이브`

### 구현 상태 표기

| 상태 | 의미 |
|---|---|
| 구현 | 현재 프로토타입에서 사용 가능한 기능 |
| 조건부 구현 | 브라우저 권한 또는 지원 여부에 따라 동작하는 기능 |
| 프로토타입 | 화면과 계산 흐름은 있으나 실제 AI 모델/API 결과는 아닌 기능 |
| 확장 예정 | 구조 또는 진입점만 있고 추가 개발이 필요한 기능 |

---

## 2. 핵심 사용자 시나리오

1. 사용자는 발표 자료를 PDF 또는 PPTX로 등록한다.
2. 발표 목표 시간과 집중 피드백 내용을 입력한다.
3. 슬라이드별로 반드시 설명할 핵심 내용을 작성하거나 자동 초안을 생성한다.
4. 카메라와 음성 인식을 사용해 슬라이드를 넘기며 발표를 녹화한다.
5. 녹화가 끝나면 가상 청중의 질문에 음성 또는 텍스트로 답한다.
6. 리포트에서 발표 시간, 슬라이드와 발화의 내용 적절성, 전달·비언어 요소, 청중 질문 답변을 확인한다.
7. 문제가 발생한 슬라이드 구간 영상을 바로 재생하고, 이전 시도와 비교하거나 다시 연습한다.

## 15. 실제 AI 연동이 필요한 항목

아래 기능은 현재 UI와 데이터 구조는 준비되어 있지만, 실제 AI 분석 결과로 보기에는 추가 모델/API 연동이 필요하다.

1. 슬라이드 내용과 발화의 의미적 일치도 평가
2. 발표 자료를 바탕으로 한 슬라이드별 핵심 내용 자동 생성
3. 발표 맥락을 반영한 청중 질문 자동 생성
4. 청중 답변의 논리성·근거·완성도 평가
5. 현재 MediaPipe 시선 정렬·자세 점수 이후의 표정·제스처 고도화 및 서버 분석
6. 음성 신호 기반 억양, 음높이, 에너지, 떨림, 휴지 분석
7. 문제 발생 시점 자동 탐지와 정확한 영상 구간 연결
8. 개인의 이전 시도에 맞춘 개선 우선순위와 코칭 문장 생성
