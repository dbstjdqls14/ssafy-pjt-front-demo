# AIVO 프론트엔드 개발 현황

> 팀 공유용 문서 · 현재 구현된 화면, 사용자 흐름, 프론트 구조와 공통 기능을 정리한다.

- ✅ 화면과 주요 동작이 프론트 코드에 연결됨 (실제 서버 미연결 시 Mock으로 대체될 수 있음)
- 🟡 화면은 구현됐지만 실제 서버·AI 데이터 연결 필요

## 3. 프론트 구조

```text
Vue Router
  → App.vue에서 Layout 선택
    → View 렌더링
      → Pinia Store: 화면 간 데이터 공유·복구
      → Composable: 카메라·마이크·녹화·분석
      → API 모듈: 서버 요청 → endpoint 이용 불가 시에만 개발용 Mock
```

| 위치 | 주요 파일·역할 |
|---|---|
| `src/views` | 홈, 인증, 마이페이지, 발표, 면접, 보관함 화면 |
| `src/layouts` | 공통 화면, 녹화 화면, 마이페이지 중첩 레이아웃 |
| `src/router/routes.js` | 전체 URL, 화면 컴포넌트, 레이아웃·인증·문서 제목 설정 |
| `src/stores` | 인증·연습 선택·발표·면접·녹화·보관함 상태 |
| `src/composables` | 홈 모션, 화면 전환, 장치 접근, 녹화, STT, 실시간 분석 |
| `src/api` | 기능 영역별 요청 함수와 공통 요청·Mock 처리 |
| `src/mocks` | API 미연동 구간의 도메인별 fallback fixture |
| `src/assets/styles` | 디자인 토큰, 공통 레이아웃, 화면별 스타일 |

### 주요 Composable

| 이름 | 역할 |
|---|---|
| `useMediaDevices` | 카메라·마이크 권한 요청, 스트림 시작·종료 |
| `useRecorder` | MediaRecorder 시작·일시정지·재개·종료, Blob 생성 |
| `useSpeechRecognition` | 브라우저 음성 인식, 발화문 수집 |
| `useRealtimePresentationAnalysis` | WPM·습관어·음량·시선·자세 실시간 측정 |
| `useHomeMotion` | 홈 스크롤 관성, 섹션 모션, 진행률·배경 변화 |
| `useHomeTransition` | 홈에서 주요 화면으로 이동할 때 전환 연출 |
| `useDebouncedCallback` | 검색 입력의 지연 호출과 예약 타이머 정리 |
| `useCountUp` | 리포트 점수 애니메이션과 interval 수명주기 관리 |

## 4. 레이아웃

| 레이아웃 | 적용 화면 | 동작 |
|---|---|---|
| `DefaultLayout` | 설정·분석·리포트·FAQ·인증·보관함 | 공통 헤더·푸터를 유지하고 본문만 교체 |
| `ImmersiveLayout` | 홈·발표 녹화·면접 녹화 | 화면별 몰입형 전체 화면 구조 사용 |
| `MyPageLayout` | `/mypage` 하위 화면 | 헤더·푸터·좌측 메뉴를 유지하고 우측 패널만 교체 |

- `App.vue`가 `route.meta.layout`에 따라 레이아웃을 선택합니다.
- 각 화면은 lazy import되어 처음 접근할 때 로드됩니다.
- 일반 화면은 keyed wrapper의 짧은 fade-up 애니메이션으로 전환됩니다.
- 녹화·홈 화면은 자체 모션을 사용하므로 일반 전환 애니메이션을 적용하지 않습니다.

## 5. 상태 저장 방식

| Store | 주요 데이터 | 저장 위치 | 새로고침 후 |
|---|---|---|---|
| `authStore` | 사용자, 인증 여부, 로그인 로딩·오류 | `localStorage`의 `aivo.user` | 사용자 정보 복구 |
| `practiceStore` | `mode`, `folderId`, `folderName`, 조회한 폴더 목록 | `sessionStorage`의 `aivo.practice-flow`(선택 정보) | 같은 탭에서 선택 정보 복구 |
| `presentationStore` | 세션 상태, 발표 설정, 파일 정보, 슬라이드, 타임라인, 발화, 분석 요약, 녹화 ID | `sessionStorage`의 `aivo.presentation-flow` | 같은 탭에서 복구 |
| `interviewStore` | 세션 상태, 지원 정보, 자료명, 면접관 스타일, 질문, 녹화 시간·ID, 분석 상태·진행률 | `sessionStorage`의 `aivo.interview-flow-v2` | 같은 탭에서 복구 |
| `recordingStore` | 녹화·일시정지 상태, 시간, 발화, 실시간 지표, Blob | 메모리 | 초기화됨 |
| `archiveStore` | 발표·면접 연습 기록과 폴더 집계 | `localStorage`의 `aivo.session-history.v2` | 기록 복구 |
| `documentsStore` | 지원 자료 목록·상세·업로드·삭제 상태 | `localStorage`의 `aivo.support-documents` | API 미연결 시 로컬 자료 복구 |

- `sessionStorage`: 현재 탭의 발표·면접 작성 상태를 유지합니다.
- `localStorage`: 로그인 사용자와 임시 보관함 기록을 브라우저 종료 후에도 유지합니다.
- 카메라·마이크 스트림과 녹화 Blob은 보안·용량 문제로 영구 저장하지 않습니다.
- Store의 `reset()`을 실행하면 해당 연습 흐름의 임시 상태도 함께 제거됩니다.

| SPA 레이아웃 유지 | 라우트 이동 시 공통 헤더·푸터를 유지하고 본문만 교체 | 일반 화면 전체 |
| 화면 분할 로딩 | Vue Router lazy import로 화면 코드를 필요할 때 로드 | 전체 라우트 |
| 페이지 전환 | 일반 화면은 짧은 fade-up, 홈·녹화는 자체 전환 사용 | 전체 화면 |
| 홈 스크롤 모션 | 단일 RAF 기반 부드러운 휠 관성, 섹션별 배경·콘텐츠·진행률 변화 | 홈 |
| 장치 권한 관리 | 카메라·마이크 권한 요청, 미리보기, 화면 이탈 시 스트림 종료 | 발표·면접 장치 확인·녹화 |
| 녹화 | MediaRecorder 기반 시작·일시정지·재개·종료와 WebM Blob 생성 | 발표·면접 |
| 음성 인식 | Web Speech API로 실시간 발화문 수집 | 발표·Q&A |
| 말하기 분석 | 발화 시간과 단어 수로 WPM 계산, 한국어 습관어 횟수 측정 | 발표 녹화 |
| 음량 분석 | Web Audio API로 입력 음량을 분석해 대기·적정·작음 상태 표시 | 발표 녹화 |
| 비언어 분석 | MediaPipe Face·Pose Landmarker로 카메라 시선과 자세 점수 계산 | 발표 장치 확인·녹화 |
| 슬라이드 연동 | 슬라이드 전환 시점·체류 시간·발화문을 같은 슬라이드 ID로 연결 | 발표 녹화·리포트 |
| 연습 폴더 연동 | 폴더 목록·검색·생성 API와 발표·면접 세션의 `folderId` 연결 | 연습 시작 흐름 |
| 면접 녹화 연동 | WebM 녹화와 질문별 답변 구간을 업로드하고 저장 완료 후 분석 시작 | 면접 녹화·분석 |
| 상세 영상 탐색 | 리포트의 `recordingUrl` 재생과 발화·문제 구간별 재생 위치 이동 | 발표 상세 리포트 |
| 진행 상태 복구 | 연습 선택과 발표·면접 설정·진행 정보를 `sessionStorage`에서 복원 | 발표·면접 설정 흐름 |
| 반응형·접근성 | 모바일 레이아웃, 키보드 탐색, `prefers-reduced-motion` 대응 | 공통 |
