# 인증 화면 반응형 및 홈 관성 스크롤 설계

## 목표

- 로그인, 회원가입, 비밀번호 찾기 화면의 데스크톱 폼 폭을 현재보다 줄인다.
- 인증 화면을 태블릿과 모바일 너비에서도 안정적으로 표시한다.
- 버튼 호버에서 보라색 그라데이션, 광택, 그림자를 제거한다.
- 홈 화면의 휠 스크롤을 튕김 없이 부드럽게 감속하는 관성 동작으로 복구한다.
- 현재 작업 트리에 남아 있는 홈 및 폴더 관련 변경을 보존한다.

## 인증 화면 레이아웃

- 세 인증 화면은 공통 `auth.css` 규칙을 사용한다.
- 데스크톱 폼 최대 폭은 `440px`로 제한한다.
- 실제 폭은 뷰포트에 맞춰 줄어드는 유동 폭으로 설정하고 모바일에서 좌우 `20px` 안팎의 여백을 유지한다.
- 충분한 높이에서는 헤더와 푸터 사이에 폼을 중앙 배치한다.
- 화면 높이가 부족한 기기에서는 콘텐츠가 잘리지 않도록 중앙 콘텐츠 영역에만 최소한의 세로 스크롤을 허용한다.
- 제목, 입력 필드, 버튼의 위계는 기존 단색 인증 디자인을 유지한다.

## 버튼 상태

- 로그인 및 제출 버튼은 짙은 남색 단색을 유지한다.
- 카카오와 구글 버튼도 각각의 단색 배경을 유지한다.
- 호버 시 `background-image`, 보라색 계열 `box-shadow`, `filter`, 가상 요소 광택을 적용하지 않는다.
- 호버 피드백은 같은 계열의 아주 약한 단색 명도 변화로 제한한다.
- 키보드 사용자를 위한 `:focus-visible` 외곽선은 유지한다.

## 홈 관성 스크롤

- 실제 문서 스크롤 위치를 단일 기준으로 사용한다.
- 데스크톱의 휠 입력은 목표 위치에 누적하고, `requestAnimationFrame`에서 현재 위치를 목표 위치 쪽으로 감속 이동한다.
- 스프링이나 반대 방향 보정값을 사용하지 않아 끝에서 되튀는 동작이 발생하지 않게 한다.
- 트랙패드의 작은 연속 입력과 일반 마우스 휠의 큰 입력을 모두 정규화한다.
- 키보드, 스크롤바 드래그, 앵커 이동은 기본 브라우저 동작을 방해하지 않는다.
- 터치 화면과 모바일에서는 브라우저의 네이티브 스크롤을 유지한다.
- `prefers-reduced-motion` 환경에서는 강제 관성을 적용하지 않고 접근성 설정을 존중한다.

## 검증

- 인증 화면용 회귀 테스트에 최대 폭, 유동 폭, 낮은 화면 스크롤, 단색 호버 규칙을 추가한다.
- 홈 관성 테스트에 입력 정규화, 단조 감속, 오버슈트 방지 조건을 추가한다.
- 관련 테스트를 먼저 실패시키고 구현 후 통과시킨다.
- JavaScript 구문, `sc-if`/`sc-for` 태그 수, CSS 중괄호 균형, 기본 홈 진입을 확인한다.
- 브라우저에서 데스크톱과 모바일 너비를 확인하고 인증 화면 호버와 홈 휠 스크롤을 직접 점검한다.
