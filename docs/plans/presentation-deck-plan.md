# AIVO 최종 발표 장표 기획안 (v2)

> v1은 참고 장표(CARe)의 연출 장치(비주얼노벨 대화창·게임 선택지·타임카드·😢😎 페어)를 그대로 차용해 폐기.
> v2는 **AIVO만이 할 수 있는 콘셉트**로 재설계. 골격 최신본: 60장 (v5 — 'AI 핵심 내용 초안' 기능 슬라이드 제외, 상태 배지 우측 상단 슬림형, 모니터 프레임 크기 통일, 기능 제목 29pt).
> ※ PPTX 파일은 `outputs/`에 로컬 보관 — `outputs/`·`*.pptx`는 .gitignore 대상이라 저장소에는 올라가지 않는다.
> v3 추가 변경: ① 캡처 자리표시 → 브라우저 창 프레임(aivo.app 주소창에 실제 라우트) ② 빌드업(1~10장)에서 서비스명 완전 비공개 — "누가 보고 있는지는, 잠시 후에 공개합니다" ③ 이름 첫 공개는 "AI + VOICE" 네이밍 타이포(11) → 로고 각인(12) 순서

## 1. 참고 장표에서 가져오는 것 (장치가 아니라 원칙만)

1. 한 슬라이드 = 한 메시지, 풀블리드 비주얼
2. 도입에서 페인포인트를 '설명'하지 않고 '겪게' 한다
3. 기술은 문제→해결→검증 반복, 트레이드오프를 정직하게
4. 마무리까지 설계 (예상 질문 카드 포함)

## 2. v2 콘셉트 — "이 발표는 지금 AIVO 위에서 진행되고 있다"

발표 덱 자체가 **AIVO의 녹화 UI**다. 남의 스토리 문법을 빌리지 않고, 우리 제품의 화면 언어(REC 인디케이터·실시간 자막 바·분석 레일·토스트·리포트 카드)로 처음부터 끝까지 말한다.

- **콜드 오픈**: 카메라 권한 요청 모달("AIVO가 카메라와 마이크를 사용하려고 합니다 → 허용")로 시작. 발표가 서비스 위에서 돈다는 선언.
- **문제 제기 = 라이브 실패 시연**: 발표자가 30초간 일부러 '못하는 발표'를 연기하고, 화면 속 AIVO UI가 실시간 반응 — 습관어 카운터 +3, 말속도 218자/분 빨간 존, "시선이 5초째 청중을 벗어나 있어요" 토스트, 목표 시간 초과. 청중이 페인포인트를 직접 목격한다.
- **전환 장치**: AIVO 리포트의 실제 버튼 **[↻ 다시 연습하기]** 클릭 연출로 서비스 소개 진입.
- **기술 브릿지 = "점수 뒤의 기술"**: 리포트 점수 카드 3장(시선·자세 92 / 내용 일치 87 / 완주한 데모 100)을 하나씩 클릭해 들어가는 줌 전환.
- **기대효과 = 성장 그래프**: 이모지 페어 대신 아카이브의 시도 1→5 점수 상승 막대그래프.
- **Q&A = 청중 질문 UI**: 서비스의 '청중 질문' 화면 그대로 — "이번엔 AI가 아니라, 진짜 청중의 질문을 받을 차례입니다."
- **수미상관**: 도입의 실패한 녹화 ↔ 마무리 "이 발표도 AIVO로 연습했습니다" + 실제 리허설 리포트 캡처.
