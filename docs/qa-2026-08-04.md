## 공통 0. 폴더에 발표/면접 타입이 없다 (P0, 6건 공통 원인)

**확인한 사실** — 폴더를 만들 때 `type`은 서버로 보내지만, 목록 응답에 타입이 없어서
프런트가 **localStorage에만 기억**한다([practiceStore.js](../src/stores/practiceStore.js) `rememberFolderType`).
그래서 새 연습 화면은 localStorage 기준으로 필터하고, 내 기록은 서버 응답 기준
(`normalizePracticeFolder` 기본값 `presentation`)으로 태그를 그린다 → **두 화면이 다른 근거를 본다.**
타입이 유실되면 폴더가 양쪽 목록에 다 뜨고, 없다고 판단해 새로 만들면 같은 이름 폴더가 하나 더 생긴다.

**필요한 작업**
- 백엔드: `practice_folder`에 타입 컬럼 + 생성 요청/목록·상세 응답 포함 + 목록 `type` 필터
  (현재 저장소의 백엔드 스냅샷에는 타입 필드가 없음)
- 프런트: 서버 타입을 단일 근거로 사용, localStorage 폴백 제거, 같은 타입 내 이름 중복 검사
- **이 순서가 정해지기 전엔 프런트만으로 근본 해결이 안 된다**(임시 방어만 가능)

여기서 파생된 항목: 1-①②③ · 2-① · 아래 각 화면 참조

1. 이미지 유실 4건 스크린샷(11번)

6. 직전 보고 2건(질문 생성 실패 / 리포트 생성 시 null)의 Network 응답 본문
