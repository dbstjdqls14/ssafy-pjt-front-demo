# 발표 강점·약점 학습 추이 화면 설계

## 목표

`내 학습 추이`의 발표 탭에서 최근 발표 기록을 이전 기록과 비교해 사용자의 강점과 개선이 필요한 약점을 알려준다. 발표 유형 라벨은 만들지 않는다. 화면에는 계산 근거의 반복 횟수와 판정식을 노출하지 않고, 최근 수치와 변화량 및 강점·약점 결과만 보여준다.

## 범위와 가정

- 최근 완료 발표 3회와 그 직전 완료 발표 3회를 비교한다.
- `NonverbalAnalysisLog`에 발표의 10초별 `bodyStability`, `outlierList`, `sideGlance`가 저장되고 조회된다고 가정한다.
- 평균 발화 속도는 발표 성향을 설명하는 참고값으로만 사용하며 강점·약점 판정에는 사용하지 않는다.
- 발표 시간이 다른 기록은 횟수가 아니라 분당 밀도 또는 시간 비율로 보정한다.
- 발표의 시선·자세·음성 지표는 사용자의 모든 발표를 비교할 수 있다.
- 슬라이드 내용 전달과 질의응답 점수는 발표 자료의 차이를 줄이기 위해 동일 폴더 기록을 우선 비교한다.
- 발표 유형 분류, 청중별 적정 속도 판정, 의미 기반 발표 스타일 분류는 범위에서 제외한다.

## 데이터 출처

| 엔티티 | 사용 데이터 | 목적 |
|---|---|---|
| `PracticeFolder` | 사용자, 폴더 | 사용자·폴더 범위 확인 |
| `Practice` | 발표 연결, `durationSec`, `createdAt` | 최근/이전 기록 선정, 시간 보정 |
| `Presentation` | `targetDurationSec` | 목표 시간 오차 계산 |
| `SpeechAnalysisLog` | 10초 구간, `metricValue`, `metadata` | WPM, 추임새, 침묵, 말더듬 계산 |
| `NonverbalAnalysisLog` | 10초 구간, `metricValue`, `metadata` | 자세 안정도, 자세 불안정, 시선 이탈 계산 |
| `PresentationSlideFeedback` | `score`, `totalFeedbackId` | 슬라이드 내용 전달 점수 |
| `PresentationQuestionFeedback` | `score`, `totalFeedbackId` | 질의응답 점수 |
| `TotalFeedback` | `practiceId` | 피드백과 연습 연결 |
| `SlideClickLog` | 슬라이드, 발생 시각 | 슬라이드 체류 시간과 재방문 합산 |

`PresentationScore`는 이번 화면의 필수 데이터가 아니다. 개별 지표를 위 엔티티에서 직접 계산한다.

## 비교 구간과 데이터 부족 처리

- 최근 구간: 완료된 발표 중 최신 3회
- 이전 구간: 그 직전 3회
- 최근 발표가 3회 미만이면 강점·약점 분석 대신 데이터 부족 상태를 표시한다.
- 총 발표가 3~5회면 최근 3회 수치는 표시한다. 이전 대비 변화량 자리에는 수치를 숨기고 회색 비활성 상태의 `이전 기록이 부족해요` 문구를 표시한다. 이때 강점·약점은 절대 기준이 있는 점수형 지표만 판정하며, 상대 변화가 필요한 밀도·변동 지표는 참고값으로만 표시한다.
- 총 발표가 6회 이상이면 최근 3회 평균과 이전 3회 평균을 비교한다.
- 특정 지표의 유효 연습이 2회 미만이면 해당 지표를 `분석 데이터 없음`으로 표시하고 강점·약점 판정에서 제외한다.
- 시선·자세는 분석 커버리지가 부족한 연습을 계산에서 제외한다. 검출 실패를 낮은 점수로 처리하지 않는다.

## 핵심 수치

화면 상단에 다음 여섯 개의 핵심 수치를 고정한다. 각 카드는 최근 3회 평균, 이전 3회 대비 변화량, 최근 3개의 작은 추이 그래프를 표시한다.

1. 슬라이드 내용 전달 점수
2. 자세 안정도
3. 시선 이탈 밀도
4. 추임새 밀도
5. 발화 속도 변동률
6. 목표 시간 오차

별도 참고 수치로 평균 발화 속도, 후반부 속도 변화, 긴 침묵 비율을 표시한다. 평균 발화 속도에는 개선·악화 색상을 사용하지 않는다.

## 지표 계산

### 슬라이드 내용 전달

슬라이드 피드백 점수를 슬라이드 체류 시간으로 가중 평균한다. 재방문은 `SlideClickLog`의 방문 구간을 모두 합산한다. 체류 시간을 계산할 수 없는 경우 단순 평균으로 폴백한다.

### 자세 안정도

유효 10초 구간의 `bodyStability.average`를 평균한다. 샘플 수가 제공되면 샘플 수로 가중한다.

### 시선 이탈 밀도

`sideGlance` 이벤트 총개수를 발표 시간(분)으로 나눈다.

### 추임새 밀도

`SpeechAnalysisLog.metadata.fillerCount` 합계를 발표 시간(분)으로 나눈다.

### 발화 속도 변동률

유효 10초 구간 WPM의 표준편차를 전체 평균 WPM으로 나누고 100을 곱한다. 평균 WPM이 0인 구간은 제외한다.

### 후반부 속도 변화

발표 앞 30%의 평균 WPM과 뒤 30%의 평균 WPM을 비교한다. 이 값은 평균 발화 속도와 함께 참고 영역에 표시하며, 변화가 반복될 때만 약점 후보로 사용한다.

### 목표 시간 오차

`|실제 시간 - 목표 시간| / 목표 시간 × 100`으로 계산한다.

### 긴 침묵 비율

`silenceDurationMs` 합계를 분석된 전체 시간으로 나누고 100을 곱한다.

## 강점·약점 판정

판정 근거는 내부 계산에만 사용하며 화면에는 노출하지 않는다.

### 강점 후보

- 점수형 지표의 최근 평균이 80점 이상이고 이전보다 악화되지 않았다.
- 또는 방향성이 정해진 지표가 이전 3회보다 의미 있게 개선됐다.
- 최근 3회 중 최소 2회가 같은 개선 방향이다.
- 유효 데이터와 분석 커버리지가 충분하다.
- 이전 구간이 없는 3~5회 상태에서는 점수형 지표가 80점 이상이고 최근 3회 중 2회 이상 80점 이상일 때만 강점으로 판정한다.

### 약점 후보

- 점수형 지표의 최근 평균이 70점 미만이다.
- 또는 방향성이 정해진 지표가 이전 3회보다 15% 이상 악화됐다.
- 최근 3회 중 최소 2회에서 같은 문제가 반복됐다.
- 유효 데이터와 분석 커버리지가 충분하다.
- 이전 구간이 없는 3~5회 상태에서는 점수형 지표가 70점 미만이고 최근 3회 중 2회 이상 70점 미만일 때만 약점으로 판정한다.

강점과 약점은 각각 최대 3개만 표시한다. 조건을 충족하는 항목이 적으면 빈자리를 임의의 항목으로 채우지 않는다.

## 화면 구조

1. 상단 요약
   - 최근 3회와 이전 3회를 비교한다는 설명
   - 발표/면접 탭은 유지하되 이번 변경은 발표 탭 목업만 대상으로 한다.
2. 최근 3회 핵심 수치
   - 여섯 개 카드
   - 최근 평균, 이전 대비 변화, 작은 추이
   - 이전 3회가 없으면 변화 영역을 회색으로 비활성화하고 `이전 기록이 부족해요`를 표시
3. 나의 강점과 개선이 필요한 부분
   - 좌우 2열 카드
   - 강점 최대 3개, 약점 최대 3개
   - 항목명과 한 줄 해석만 표시하고 반복 횟수와 계산 근거는 숨긴다.
4. 발표 흐름 참고
   - 평균 WPM, 초반/후반 WPM, 후반부 변화율, 긴 침묵 비율
   - 평균 속도에는 좋음·나쁨 판정을 하지 않는다.
5. 최근 3회와 이전 3회 추이
   - 핵심 지표를 선택해 6회 흐름을 비교한다.
   - 이전 3회가 없으면 차트의 이전 구간을 회색 빈 영역으로 유지하고 `이전 기록이 부족해요`를 표시한다. 최근 3회 구간은 정상 표시한다.
6. 다음 연습 목표
   - 가장 우선순위가 높은 약점 하나에서 도출한다.

## 데이터 흐름과 API

현재 사용자 발표 6회의 관련 로그를 한 번에 조회하는 API가 없으므로 조회 API가 필요하다.

```http
GET /api/v1/users/me/presentation-trends?recentCount=3&previousCount=3
```

백엔드는 사용자 소유권을 검증하고 최대 6회의 연습·로그·피드백을 연습 단위로 반환한다. 프런트는 최근/이전 평균, 변화량, 강점·약점 후보를 계산한다.

목업 단계에서는 같은 응답 모양의 정적 데이터를 사용한다. 화면에는 `API` 또는 `MOCK` 배지를 표시하지 않는다.

## 오류와 빈 상태

- 최근 완료 발표 0회: 연습 시작 안내
- 최근 완료 발표 1~2회: 세 번 이상 연습해야 분석할 수 있다는 안내
- 최근 완료 발표 3~5회: 최근 수치와 점수형 지표의 강점·약점은 표시한다. 이전 대비 변화와 차트의 이전 구간은 회색 비활성 상태로 두고 `이전 기록이 부족해요`를 표시한다.
- 일부 지표 누락: 해당 카드만 분석 데이터 없음 처리
- API 실패: 오류 메시지와 다시 시도 버튼 표시. 실제 연동 시 가짜 강점·약점으로 대체하지 않는다.

## 검증 기준

- 최근 3회와 이전 3회가 날짜순으로 정확하게 분리된다.
- 낮을수록 좋은 지표의 증감 방향이 반대로 표시되지 않는다.
- 평균 WPM이 강점 또는 약점으로 분류되지 않는다.
- 데이터가 부족한 지표가 0점으로 표시되지 않는다.
- 유효하지 않은 시선·자세 구간이 낮은 점수로 계산되지 않는다.
- 강점·약점은 각각 최대 3개이며 조건 미충족 시 억지로 채우지 않는다.
- 이전 3회가 없을 때 변화량과 차트의 이전 구간이 회색 비활성 상태이며 `이전 기록이 부족해요` 문구가 보인다.
- 1440px 및 모바일에서 핵심 수치와 강점·약점 카드가 잘리지 않는다.
