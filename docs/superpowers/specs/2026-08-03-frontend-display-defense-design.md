# Frontend Input And Display Defense Design

## Goal

사용자가 입력하거나 API에서 받은 긴 문자열·긴 소수·비정상 숫자가 폼, 목록, 카드, 상세 화면의 레이아웃을 깨뜨리지 않도록 전체 프런트 표시 경계를 통일한다.

## Input rules

- 아이디·닉네임: 4~20자, 영문·숫자·밑줄만 허용한다.
- 폴더명: 1~20자.
- 발표·면접 연습 이름: 1~50자.
- 연습 설명: 최대 100자.
- 자소서·포트폴리오 제목: 1~50자.
- 폴더·연습 검색어: 최대 50자.
- 업로드 파일명은 로컬 파일명을 바꾸거나 거부하지 않는다.
- 입력 컨트롤의 `maxlength`, 글자 수 표시, 제출 직전 검증이 같은 상수를 사용한다.

## Display rules

- 한 줄 제목은 `min-width: 0`, `overflow: hidden`, `text-overflow: ellipsis`, `white-space: nowrap`을 적용한다.
- 두 줄까지 허용하는 제목은 line-clamp를 사용한다.
- 말줄임된 제목에는 원문을 확인할 수 있도록 `title`을 제공한다.
- 설명·발화·피드백처럼 본문 성격의 문자열은 `overflow-wrap: anywhere`로 컨테이너 안에서 줄바꿈한다.
- 이미 서버에 저장된 긴 값은 자르거나 다시 저장하지 않고 표시만 방어한다.

## Numeric rules

- 점수·자세 안정도는 0~100의 유한 숫자만 표시하고 정수로 반올림한다.
- 횟수는 0 이상의 유한 숫자만 정수로 표시한다.
- 밀도, 비율, WPM, 초 단위 값은 최대 소수점 한 자리로 표시하고 불필요한 `.0`을 제거한다.
- 변화량은 지표 단위에 맞춰 최대 소수점 한 자리로 표시한다.
- `NaN`, `Infinity`, 빈 문자열, 도메인 범위를 벗어난 점수는 `-`로 표시한다.
- 원본 API 값은 보존하고 화면용 표시값만 별도로 만든다.
- 모든 포맷 결과는 천 단위 구분을 사용하며 긴 숫자가 카드 밖으로 넘치지 않게 한다.

## Scope

- 회원가입과 마이페이지 프로필
- 발표·면접 폴더 선택 및 생성
- 발표·면접 연습 설정
- 자소서·포트폴리오 등록 및 목록
- 내 기록 폴더 목록·상세
- 발표·면접 리포트와 내 학습 추이의 수치 표시

## Validation

- Vitest로 입력 제한, 제출 방어, 기존 긴 값 말줄임 속성, 숫자 포맷을 검증한다.
- 전체 Vitest와 Vite 프로덕션 빌드를 실행한다.
- 폴더 생성, 발표 설정, 회원가입, 학습 추이 화면을 데스크톱과 좁은 화면에서 확인한다.
