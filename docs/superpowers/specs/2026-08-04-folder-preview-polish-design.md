# 폴더 미리보기 UI 정돈 설계

## 목표

발표·면접의 기존 폴더 선택 화면을 기준 시안의 비율과 정보 밀도에 가깝게 정돈하고, 완료된 연습이 없는 폴더의 점수·최근 연습 값을 `-`로 표시한다.

## 범위

- 기존 API 응답과 폴더·연습 데이터 흐름은 유지한다.
- 폴더 목록의 선택 상태는 `folder.id`만 사용한다.
- 선택된 행에만 강조 배경을 적용한다.
- 우측 패널은 `폴더명 → 최고 점수 → 최근 연습 최대 3개` 순서로 표시한다.
- 완료된 연습이 없으면 목록 점수, 최고 점수, 최근 연습 영역에 `-`를 표시한다.
- 로딩 중과 요청 실패는 빈 데이터와 구분하여 기존 안내 문구를 유지한다.
- 발표와 면접 화면에 같은 표시 규칙을 적용한다.

## 시각 규칙

- 기준 시안처럼 우측 요약 패널의 제목, 점수 행, 구분선, 최근 연습 행을 조밀하게 배치한다.
- 고정 해상도에 맞춘 좌표 하드코딩 대신 기존 그리드 안에서 상대 너비와 여백을 조정한다.
- 긴 폴더명은 한 줄 말줄임을 유지한다.

## 검증

- 완료된 연습이 없는 응답에서 `데이터 없음`, `최근 점수 없음`, `완료된 연습 기록이 없습니다.`가 노출되지 않고 각 값이 `-`로 표시되는지 컴포넌트 테스트한다.
- 완료 기록이 있는 경우 최고 점수와 최근 3회가 기존대로 표시되는지 회귀 테스트한다.
- 발표·면접 타입별 렌더링에 동일한 규칙이 적용되는지 기존 파라미터 테스트를 유지한다.
