# 폴더 선택 미리보기 단순화 설계

## 목표

기존 폴더 선택 화면의 오른쪽 상세 영역을 폴더 식별에 필요한 정보만 보여주도록 단순화한다.

## 화면 구성

- 선택된 폴더의 이름을 한 줄로 표시한다.
- 이름이 영역 너비를 넘으면 말줄임표로 처리하고 `title` 속성으로 원문을 제공한다.
- 폴더 설명을 이름 아래에 표시한다.
- 설명이 비어 있으면 회색 보조 문구로 `등록된 설명이 없습니다.`를 표시한다.
- `최고 점수`, 점수 값 또는 `데이터 없음`, `최근 연습` 목록은 렌더링하지 않는다.
- 왼쪽 폴더 목록의 유형·연습 횟수 배지와 선택 동작은 변경하지 않는다.
- 선택할 폴더가 없을 때의 기존 `새 폴더를 만드세요` 안내는 유지한다.

## 데이터

기존 `normalizePracticeFolder`가 제공하는 `name`과 `description`만 사용한다. API 계약이나 저장 방식은 변경하지 않는다.

## 검증

- 폴더 선택 시 이름과 설명이 표시되는지 확인한다.
- 점수와 최근 연습 관련 문구 및 DOM이 제거되는지 확인한다.
- 설명이 없는 폴더에서 대체 문구가 표시되는지 확인한다.
- 기존 폴더 선택 후 다음 단계 이동이 유지되는지 회귀 검증한다.
