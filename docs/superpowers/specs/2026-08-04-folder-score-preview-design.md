# 폴더 선택 점수 미리보기 설계

## 목표

발표와 면접에서 공통으로 사용하는 폴더 선택 화면의 오른쪽 영역을 폴더 설명 중심 화면에서 완료된 연습의 점수 요약 화면으로 변경한다. 중간에 중단된 연습이나 리포트가 생성되지 않은 연습은 통계와 회차에 포함하지 않는다.

## 데이터 계약

- 폴더 목록은 `GET /api/v1/practice-folders/archive?type={presentation|interview}` 응답을 기준으로 보강한다.
  - `recentScore`: 왼쪽 폴더 행의 최근 점수 배지
  - `maxScore`: 오른쪽 상세 영역의 최고 점수
  - `attemptCount`: 완료된 리포트 기준 연습 횟수
- 선택한 폴더의 최근 기록은 `GET /api/v1/practice-folders/{folderId}/practices?page=0&sort=latest`에서 가져온다.
  - `attemptCount`: 최근 기록의 회차 계산 기준
  - `practices[].overallScore`: 점수
  - `practices[].createdAt`: 날짜
- 두 API 모두 Spring의 점수 테이블과 연결된 완료 연습만 반환하므로 프런트에서 임의 점수를 만들지 않는다.

## 화면 동작

- 발표 경로에서는 발표 폴더만, 면접 경로에서는 면접 폴더만 유지한다.
- 왼쪽 폴더 행에는 폴더명, 유형, 완료 연습 횟수와 최근 점수 배지를 표시한다.
- 오른쪽 미리보기에는 폴더명, 최고 점수와 최신 완료 연습 최대 3개를 표시한다.
- 기록이 1~2개면 존재하는 기록만 표시한다.
- 점수 기록이 없으면 가짜 행을 만들지 않고 `완료된 연습 기록이 없습니다.`를 표시한다.
- 날짜는 오늘이면 `오늘`, 아니면 `M월 D일`로 표시한다.
- 긴 폴더명은 기존 말줄임 및 `title` 접근 방식을 유지한다.

## 비동기 상태와 오류 처리

- 선택된 폴더 ID가 바뀔 때 최근 기록을 조회한다.
- 요청 순번을 증가시켜 빠른 연속 선택에서 이전 응답이 새 선택을 덮어쓰지 못하게 한다.
- 조회 중에는 오른쪽 영역에 로딩 상태를 표시한다.
- 최근 기록 조회만 실패하면 폴더 선택 자체는 유지하고, 오른쪽 영역에 기록을 불러오지 못했다는 안내를 표시한다.
- 폴더 목록 조회 실패 처리는 기존 동작을 유지한다.

## 변경 범위

- `FolderSelectView.vue`: 선택 폴더 기록 조회와 렌더링
- `practiceStore.js`: archive 통계 보강 및 선택 폴더 최근 기록 상태
- `folder-select.css`: 두 번째 시안에 맞는 점수·최근 기록 레이아웃
- 관련 API/Store/View 테스트

백엔드, 면접·발표 녹화 로직과 리포트 화면은 수정하지 않는다.

## 검증

- 발표와 면접 타입별 표시
- 완료 기록 0개, 1개, 3개 이상
- 빠르게 폴더를 바꿀 때 최신 선택만 반영
- 점수가 없는 응답에서 가짜 값 미표시
- 기존 폴더 생성 및 다음 단계 이동 회귀
- 전체 단위 테스트와 프로덕션 빌드
