# 실시간 말하기 속도 및 녹화 장치 제어 설계

## 목표

발표와 면접의 실시간 말하기 속도가 전체 누적 평균 때문에 `느림`으로 고정되는 문제를 해결하고, 녹화 중 장치 제어를 명확하게 한다.

## 말하기 속도

- 발표와 면접 모두 최근 5초 동안 새로 인식된 한글 음절 수를 사용한다.
- 매초 현재 STT 전체 음절 수와 직전 음절 수의 차이를 표본으로 기록한다.
- 최근 5개 표본의 새 음절 수 합계를 표본 시간으로 나누어 초당 음절을 계산한다.
- Chrome STT가 중간 문장을 수정하여 전체 음절 수가 감소하면 해당 표본은 0으로 처리한다.
- 최근 5초 동안 새 음절이 없으면 측정값 없음 상태로 표시한다.
- 기존 공통 구간을 사용해 4음절/초 미만은 `느림`, 4~6은 `보통`, 6 초과는 `빠름`으로 표시한다.
- 질문 또는 녹화 세션이 시작될 때 이동 구간 표본을 초기화한다.

## 장치 제어

- 면접 화면의 `멈추기 / 다시 시작` 버튼과 관련 일시정지 동작을 제거한다.
- 면접 진행 중에는 카메라와 마이크 토글을 계속 잠근다.
- 발표는 기존 일시정지 기능을 유지한다.
- 발표 일시정지 상태에는 `다시 시작하면 카메라와 마이크가 자동으로 켜집니다.` 안내를 표시한다.
- 발표 재개 시 카메라와 마이크를 먼저 켠 뒤 녹화·WAV 수집·STT를 재개한다.

## 영향 범위

- 발표와 면접 화면은 각각 독립된 UI 구조를 유지한다.
- 공유하는 것은 순수한 최근 구간 말하기 속도 계산 유틸리티뿐이다.
- complete 요청, 10초 WAV 분석, STT 전문 저장, 리포트 계약은 변경하지 않는다.

## 검증

- 느린·보통·빠른 최근 음절 표본이 각각 올바른 라벨로 표시되는지 확인한다.
- 오래된 침묵이 최근 빠른 발화 판정을 계속 낮추지 않는지 확인한다.
- 면접 화면에 일시정지 버튼이 렌더링되지 않는지 확인한다.
- 면접 진행 중 장치 토글 잠금이 유지되는지 확인한다.
- 발표 일시정지 중 안내 문구가 표시되고 재개 후 사라지는지 확인한다.
- 발표 재개 시 카메라와 마이크 트랙이 활성화되는지 확인한다.
