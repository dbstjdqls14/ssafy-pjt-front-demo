# 실시간 말하기 속도 및 리포트 단위 통일 설계

## 목표

실시간 말하기 속도가 실제 체감보다 자주 `느림`으로 표시되는 현상을 줄이고, 발표 리포트에 남아 있는 WPM 표기를 면접 리포트와 동일한 `초당 어절` 단위로 통일한다.

## 실시간 판정 기준

- `느림`: 초당 음절 수가 2.5 미만
- `보통`: 초당 음절 수가 2.5 이상 4.0 이하
- `빠름`: 초당 음절 수가 4.0 초과
- 측정값이 없거나 0 이하이면 기존처럼 `--`를 표시한다.

발표와 면접이 함께 사용하는 `speechPace` 공통 판정 유틸의 경계값만 변경한다. Chrome STT 텍스트에서 초당 음절 수를 계산하는 방식은 변경하지 않는다.

## 발표 리포트 표시 단위

- 서버 응답과 내부 그래프 데이터는 기존 WPM 값을 유지한다.
- 사용자에게 보이는 발표 리포트 속도는 `WPM / 60`으로 계산한 `초당 N.NN어절` 형식으로 표시한다.
- 평균 속도, 그래프 측정 범위, 가장 느린 구간, 가장 빠른 구간을 같은 형식으로 통일한다.
- 접근성 문구의 그래프 설명도 `10초 구간별 초당 어절 수`로 바꾼다.
- 예: `42 WPM`은 `초당 0.70어절`, `672 WPM`은 `초당 11.20어절`이다.

## 적용 범위

- 프런트엔드만 변경한다.
- 백엔드 응답 DTO, 저장 데이터, 점수 계산은 변경하지 않는다.
- 면접 리포트 UI는 현재 동작을 유지한다.

## 검증

- 2.4는 `느림`, 2.5와 4.0은 `보통`, 4.1은 `빠름`으로 판정되는 단위 테스트를 먼저 추가한다.
- 발표 리포트의 평균, 측정 범위, 느린/빠른 구간에 `WPM`이 남지 않고 `초당 N.NN어절`이 표시되는 컴포넌트 테스트를 추가한다.
- 관련 단위 테스트와 프런트 빌드를 실행한다. 브라우저 검증은 사용자가 직접 진행한다.
