# 업로드·폴더 삭제·발표 상태 경계 개선 설계

## 목표

- 면접 자료는 PDF만 선택·등록할 수 있게 하고, 잘못된 파일에는 사용자가 다음 행동을 알 수 있는 한국어 오류를 표시한다.
- 연습 폴더 상세 카드에서 기존 삭제 API를 호출해 폴더와 연관 리포트를 삭제할 수 있게 한다.
- 발표 일시정지 중에는 녹음·STT뿐 아니라 MediaPipe와 1초 단위 실시간 분석 누적도 완전히 멈춘다.
- 발표 중 이전 슬라이드 이동을 막고, 다음 슬라이드 이동은 서버 로그 저장 성공 후에만 화면에 반영한다.

## 범위 제외

- 발표 자료 업로드 진행 표시 개선은 이번 작업에서 제외한다.
- Spring/FastAPI 및 데이터베이스는 수정하지 않는다.

## 설계

### 면접 PDF 검증

파일 입력의 `accept`를 PDF로 제한하되 브라우저 필터만 신뢰하지 않는다. 선택 이벤트에서 파일 확장자와 MIME 타입을 다시 검사한다. 실패 문구는 `PDF 파일만 업로드할 수 있어요. PDF 파일을 선택해 주세요.`로 통일하고 업로드·제목 입력 단계로 진행하지 않는다.

### 폴더 삭제

오른쪽 폴더 상세 카드 제목 행에 선택 폴더 전용 X 버튼을 둔다. 클릭 시 애플리케이션 내부 모달을 열고 `폴더를 삭제하시겠습니까?`와 `관련 리포트도 모두 삭제됩니다.`를 표시한다. 확인하면 기존 `DELETE /api/v1/practice-folders/{folderId}`를 한 번만 호출한다. 요청 중에는 확인·취소·다른 삭제 동작을 잠그며, 성공 후 삭제된 ID를 문자열 기준으로 목록에서 제거하고 남은 첫 폴더를 선택한다. 실패하면 기존 선택과 목록을 유지하고 오류를 노출한다.

### 발표 일시정지

일시정지 진입은 녹화, PCM, STT와 함께 `faceAnalysis.stop()`을 호출한다. 1초 tick은 `recording.isPaused`일 때 즉시 반환해 수치와 감지 누적을 막는다. 재개는 장치 상태를 검증한 기존 경로에서만 `faceAnalysis.start(video)`를 다시 호출한다. 전환 게이트를 유지해 일시정지 버튼 연타가 pause/resume 순서를 뒤집지 못하게 한다.

### 슬라이드 이동

이전 버튼은 발표 화면에서 항상 비활성화한다. 다음 이동은 단일 비동기 트랜잭션으로 처리한다. 전환 요청 중에는 다음·일시정지·종료 등 충돌 가능한 동작을 기존 전환 게이트로 잠근다. Store는 서버의 슬라이드 이동 로그 저장이 성공한 뒤에만 현재 방문 종료, 새 방문 추가, 현재 슬라이드 인덱스 변경을 커밋한다. 실패 시 화면과 로컬 타임라인은 기존 슬라이드에 남는다.

## 검증

- 면접 파일 입력이 PDF만 허용하고 비-PDF 선택 시 한국어 오류를 표시하는지 단위 테스트한다.
- 폴더 삭제 모달, API 1회 호출, 성공 후 선택 복구, 실패 시 상태 유지 여부를 테스트한다.
- 일시정지 시 MediaPipe 중단과 tick 무시, 재개 시 재시작을 테스트한다.
- 이전 이동 비활성화, 다음 이동 연타 차단, API 성공 전 화면 유지, 실패 시 롤백 불필요 상태를 테스트한다.
