# AIVO 레이아웃 개선 목업 설계

## 목적

현재 AIVO의 색상과 브랜드 인상은 유지하면서 카드 크기, 콘텐츠 폭, 글자 위계, 여백과 정렬만 개선한 데스크톱 목업을 제공한다. 목업은 구현 지시서가 아니라 사용자가 화면별 방향을 빠르게 비교하고 선택하기 위한 시각 자료다.

## 산출물

- 대화 안에서 확인할 수 있는 선택형 시각 목업 1개
- 내부에 8개 화면을 각각 독립된 1440×900 데스크톱 프레임으로 구성
- 화면 선택 탭으로 목업을 전환
- 각 화면 아래에 핵심 레이아웃 변경점 3개 표시
- 실제 프런트 소스는 변경하지 않음

## 공통 표현 원칙

- 현재 AIVO의 흰 배경, 남색 텍스트, 보라색 강조와 SUIT 계열 인상을 유지한다.
- 새로운 기능이나 데이터를 추가하지 않는다.
- 페이지 제목은 28–32px, 섹션 제목은 20–24px, 본문은 15–16px, 보조 설명은 13–14px 수준의 위계로 표현한다.
- 간격은 8px 기반의 8, 12, 16, 24, 32, 48, 64px 범위로 제한한다.
- 폼 콘텐츠 폭은 약 760px, 일반 데이터 화면은 약 1080px, 목록·두 열 화면은 약 1180px을 기준으로 한다.
- 카드 내부 여백은 20–24px, 카드 간격은 16–24px을 기본으로 한다.
- 목업의 색상 차이가 아니라 공간 구조가 먼저 읽히도록 장식과 그림자는 억제한다.

## 화면별 구성

### 1. 홈

- 첫 화면 높이를 100vh 안에 맞추고 다음 섹션의 시작을 하단에 살짝 노출한다.
- 우측 섹션 내비게이션의 점유 폭을 줄여 제목과 주요 CTA가 중앙 콘텐츠 영역 안에 남도록 한다.
- 영웅 제목, 설명, CTA를 한 묶음으로 두고 장식 영역과 명확히 분리한다.

### 2. 새 연습 선택

- `연습 유형 선택` 페이지 제목과 한 줄 설명을 상단에 추가한다.
- 발표·면접 카드는 약 380px 높이로 줄이고 카드 간격을 40px 내외로 맞춘다.
- 카드 안은 유형, 제목, 설명, 핵심 기능, 행동 표시 순서로 정돈한다.

### 3. 발표 설정

- 상단 단계 표시를 36–40px 높이로 키우고 현재 단계와 이후 단계를 명확히 구분한다.
- 760px 폼 폭은 유지하되 제목, 라벨, 입력, 도움말 사이의 간격을 통일한다.
- 이전·다음 버튼은 폼 하단과 가까이 두고 업로드 영역과 시간 설정의 밀도를 조절한다.

### 4. 면접관 선택

- 인물 이미지 크기는 유지하고 화면 제목을 28px로 키운다.
- 카드 세 개는 동일 높이로 유지하되 설명과 예시 질문의 간격을 분리한다.
- 예시 질문은 최대 세 줄 안에서 읽히도록 하고 이전·다음 버튼을 카드 그룹과 가깝게 둔다.

### 5. 면접 녹화

- 왼쪽 질문 패널은 약 230px, 오른쪽 정보 패널은 약 270px로 줄인다.
- 중앙 영상 영역을 최소 760px 수준으로 확보한다.
- 질문과 영상, 녹화 제어를 하나의 중심 흐름으로 묶고 실시간 정보는 보조 영역으로 낮춘다.

### 6. 내 기록

- 제목을 32px로 줄이고 왼쪽 정렬한다.
- 유형 탭과 검색창을 한 줄 도구 모음으로 배치한다.
- 목록과 선택 상세 카드를 같은 시작선에 맞춰 첫 화면에서 핵심 기록과 요약이 함께 보이게 한다.

### 7. 내 학습 추이

- 핵심 지표 6개 카드는 유지하되 카드 높이와 보조 문구 크기를 정돈한다.
- 발표 흐름 4개 지표는 개별 카드 대신 하나의 가로 지표 행으로 합친다.
- 강점·약점은 내용 높이에 맞추며 차트와 추천 목표까지의 섹션 리듬을 단순화한다.

### 8. 발표 리포트 상세

- 상단에 요약, 음성·몸짓, 영상, 내용 피드백, Q&A 로컬 내비게이션을 둔다.
- 슬라이드 제목은 상세 영역에서 한 번만 길게 보여주고 목록에서는 짧은 이름만 사용한다.
- 영상·발화와 피드백의 본문 폭을 제한해 긴 문장을 읽기 쉽게 만든다.

## 상호작용

- 상단 화면 선택 탭으로 8개 목업을 전환한다.
- 최초 화면은 `내 기록`으로 설정한다. 가장 큰 공간 개선 효과를 바로 보여주기 때문이다.
- 탭 선택 외에 제품 동작을 흉내 내는 추가 상호작용은 만들지 않는다.

## 완료 기준

- 8개 화면 모두 서로 독립적으로 식별된다.
- 736px 대화 폭에서 목업 전체가 비율을 유지해 축소되고 가로로 잘리지 않는다.
- 320px에서도 화면 선택 탭과 변경점 설명이 겹치지 않고 줄바꿈된다.
- 실제 AIVO의 주요 문구와 화면 구조가 유지되어 변경 방향을 바로 비교할 수 있다.
- 각 화면에서 평가에서 지적한 공간 문제가 구체적인 배치 변화로 표현된다.

## 범위 밖

- 모바일 제품 화면 재설계
- 색상·브랜드 리뉴얼
- 새로운 기능, 메뉴 또는 데이터 추가
- 현재 화면과 개선 화면의 나란한 비교
