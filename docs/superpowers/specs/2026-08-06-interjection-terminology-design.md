# 추임새 용어 통일 설계

## 목표

사용자에게 노출되는 `필러`, `필러워드`, `필러어` 표현을 `추임새`로 통일한다. 발표·면접 리포트뿐 아니라 실시간 분석, 홈 데모, 학습 추이, 서버 분석 메시지에서도 같은 용어를 사용한다.

## 변경 범위

- 프런트 화면 문구, 툴팁, 튜토리얼, 토스트, 접근성 라벨
- 프런트 목업과 화면 문구를 검증하는 테스트
- Spring 리포트 DTO에 포함되는 한국어 지표명과 분석 메시지
- FastAPI 음성 분석 피드백과 관련 테스트
- 분석 프롬프트, 코드 주석 및 현재 동작을 설명하는 프로젝트 문서의 한국어 용어

표현은 다음처럼 통일한다.

| 기존 표현 | 변경 표현 |
|---|---|
| 필러 | 추임새 |
| 필러워드 | 추임새 |
| 필러어 | 추임새 |
| 필러 밀도 | 추임새 밀도 |

## 유지 범위

API와 저장 데이터의 호환성을 위해 다음 내부 계약은 변경하지 않는다.

- `filler`, `fillerCount`, `fillerEvents`, `fillerTotal`, `totalFillerCount`
- 서버 enum/분석 종류의 `FILLER`
- `is-filler`, `iv-pace-filler-dot` 등 CSS 클래스와 DOM 데이터 속성
- 함수·변수·파일명에 포함된 영문 `filler`

## 데이터 흐름

분석 모델과 API는 기존 영문 `filler` 필드를 계속 사용한다. Spring과 FastAPI가 사용자용 한국어 라벨·메시지를 만들 때만 `추임새`로 출력하고, 프런트는 동일한 한국어 라벨로 표시 및 매칭한다. 따라서 스키마 변경이나 데이터 마이그레이션은 필요 없다.

## 검증

1. 프런트 프로덕션 소스에 한국어 `필러`, `필러워드`, `필러어`가 남으면 실패하는 용어 계약 테스트를 추가한다.
2. FastAPI 피드백 테스트의 기대 문구를 `추임새`로 변경해 서버 메시지를 검증한다.
3. 기존 프런트 테스트와 프로덕션 빌드를 실행한다.
4. 저장소 전체를 검색해 사용자 노출 가능한 한국어 기존 용어가 남지 않았는지 확인한다.
