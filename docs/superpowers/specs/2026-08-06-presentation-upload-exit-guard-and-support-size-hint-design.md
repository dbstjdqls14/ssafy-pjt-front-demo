# 발표 업로드 이탈 확인 및 지원 자료 용량 표시 설계

## 목표

발표 자료 업로드 중 사용자가 하단 이전 버튼이나 브라우저 뒤로가기로 화면을 실수로 떠나는 것을 막고, 사용자가 확인한 경우에만 이전 화면으로 이동한다. 면접 설정의 자기소개서·포트폴리오 등록 버튼에는 실제 파일 제한과 일치하는 `최대 50MB` 안내를 오른쪽에 표시한다.

## 발표 업로드 중 이탈 확인

### 대상 동작

- 업로드 전에는 하단 이전 버튼과 브라우저 뒤로가기가 즉시 동작한다.
- `다음` 버튼을 눌러 `isSubmitting`이 활성화된 동안 하단 이전 버튼이나 Vue Router가 처리하는 브라우저 뒤로가기를 누르면 이동을 취소하고 동일한 확인 모달을 표시한다.
- 새로고침과 탭 닫기는 이번 범위에 포함하지 않는다.

### 확인 모달

- 제목: `발표 자료를 업로드 중이에요`
- 설명: `업로드가 끝나기 전에 이전 화면으로 돌아갈까요?`
- `업로드 계속하기`: 모달을 닫고 현재 화면에 머문다.
- `이전 화면으로 돌아가기`: 한 번만 라우트 이탈을 허용하고 사용자가 요청한 이전 경로로 이동한다.

하단 이전 컨트롤은 `RouterLink` 대신 버튼과 명시적인 이동 함수로 바꾼다. 업로드 중에도 확인 모달을 열 수 있어야 하므로 네이티브 `disabled` 속성은 사용하지 않으며, 즉시 이동만 잠근다.

### 비동기 경합 방어

사용자가 이전 화면으로 돌아가기를 선택해도 이미 서버로 전송된 요청을 브라우저가 확실하게 취소할 수는 없다. 따라서 현재 제출 시도를 `abandoned` 상태로 표시한다. 업로드가 나중에 완료되더라도 해당 제출 시도는 `/presentation/slides`로 이동시키지 않는다.

업로드가 먼저 완료되면 내부 성공 이동을 한 번 허용하고 확인 모달을 닫은 뒤 기존처럼 슬라이드 화면으로 이동한다. 업로드가 실패하면 `isSubmitting`이 해제되어 이후 이전 버튼과 브라우저 뒤로가기가 다시 즉시 동작한다.

## 지원 자료 버튼의 50MB 안내

면접 설정의 `자기소개서 등록`, `포트폴리오 등록` 버튼에만 `최대 50MB` 보조 문구를 추가한다. 기존 자료 선택 버튼은 변경하지 않는다.

- 등록 제목은 기존 버튼 중앙에 유지한다.
- `최대 50MB`는 버튼 오른쪽 끝에 작은 회색 글씨로 배치한다.
- 제목의 실제 중앙 정렬을 유지하기 위해 보조 문구는 절대 위치로 배치하고, 버튼에는 오른쪽 안전 여백을 둔다.
- 좁은 화면에서는 보조 문구의 글자 크기와 오른쪽 여백을 줄여 제목과 겹치지 않게 한다.

버튼에 제한을 표시하는 것에 그치지 않고, 파일 선택 직후 기존 `validateSupportDocumentFile()`을 사용해 PDF 형식, 빈 파일, 50MB 초과를 검사한다. 잘못된 파일은 제목 입력과 API 호출 전에 기존 오류 영역에 표시한다. 정확히 50MB인 파일은 허용하고 1바이트 초과 파일은 거부한다.

## 테스트 및 완료 기준

- 업로드 전 하단 이전 버튼은 폴더 선택 화면으로 이동한다.
- 업로드 중 하단 이전 버튼과 브라우저 뒤로가기는 이동하지 않고 확인 모달을 표시한다.
- `업로드 계속하기`는 현재 화면을 유지한다.
- `이전 화면으로 돌아가기`는 요청한 이전 경로로 이동하며, 늦게 완료된 업로드가 슬라이드 화면으로 되돌리지 않는다.
- 정상 업로드 완료는 기존처럼 슬라이드 화면으로 이동한다.
- 자기소개서·포트폴리오 등록 버튼에만 `최대 50MB`가 표시된다.
- 면접 설정에서 50MB 초과 파일은 업로드 API와 제목 prompt 호출 전에 거부된다.
- 관련 Vitest, 전체 테스트와 프로덕션 빌드가 통과한다.

## 비범위

- 진행 중인 서버 업로드 요청의 강제 취소
- 브라우저 새로고침·탭 닫기 방어
- 기존 자료 선택 버튼의 용량 표시
- 백엔드 파일 제한 변경
