# 면접 리포트 질문 전환 표시 설계

## 목표

면접 리포트의 음성·몸짓 그래프에서 `여기서 다음으로 넘어감` 표시가 실제 영상의 다음 질문 시작 시각과 일치하게 한다.

## 확인된 원인

현재 질문 1의 실제 종료 시각은 58초지만 음성 분석의 마지막 버킷은 40초에 끝난다. UI는 마지막 분석 버킷의 `endSec`을 질문 전환 시각으로 사용해 40초에 안내를 표시한다. 분석 데이터 범위와 질문 재생 경계는 서로 다른 개념이므로 이 계산은 성립하지 않는다.

## 동작 설계

- 질문 단위 그래프에서 다음 질문 전환 지점은 현재 질문의 실제 종료 지점인 그래프 오른쪽 끝 `100%`로 표시한다.
- 현재 질문이 마지막 질문이면 `여기서 다음으로 넘어감` 표시를 렌더링하지 않는다.
- 현재 질문이 제한 시간 전에 끝난 경우에만 전환 안내를 표시하는 기존 조건은 유지한다.
- 음성 분석 버킷과 몸짓 분석 버킷의 마지막 시각은 그래프 데이터 범위에만 사용하고 질문 전환 판정에는 사용하지 않는다.
- 영상 재생, 질문 선택, 자막 타임라인 계산은 변경하지 않는다.

## 검증

- 분석 버킷이 질문 종료 전 끝나도 전환 안내가 `100%`에 표시되는 컴포넌트 테스트를 추가한다.
- 마지막 질문에서는 전환 안내가 없는 테스트를 추가한다.
- 기존 면접 리포트 테스트, 전체 Vitest, Vite 프로덕션 빌드를 실행한다.
