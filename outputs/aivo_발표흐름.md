# aivo 발표 흐름 (기획안)

기존 초본 55장 → **36장**(본편 31 + 예상질문 5). 핵심: 기능은 **리포트 하나**만, 세 갈래(음성·몸짓·내용)로.

---

## 01. 문제 정의 — 9장

| 슬라이드 | 비고 |
|---|---|
| 섹션 표지 — 혼자 하는 연습이 왜 어려운가 | |
| 잠시만요. | 앞의 더듬는 발표를 끊는 장 |
| 여러분은 방금 발표에서 어떤 문제를 발견하셨나요? | |
| 발표가 매끄럽지 않았다는 건 누구나 느낄 수 있습니다 | |
| 나는 관대하다. 스스로에게. + 연구 인용 | 기존 8+9 합침 |
| 방금 발표 분석 결과 — 추임새 9회 / 침묵 4회 / 시선 이탈 3회 | **뒤에서 회수할 숫자** |
| 하지만 혼자서는 무엇이, 얼마나, 언제 반복됐는지 알기 어렵습니다 | |
| 놓치는 것은 말하기입니다 — **음성 · 몸짓 · 내용** | 용어 통일 (기존 "말하기·태도·내용") |
| 지금까지의 연습 방법 — 거울 / 스터디 / 기존 AI 면접 | |

## 02. 서비스 소개 — 6장

| 슬라이드 |
|---|
| 그래서, 만들었습니다. |
| 말하기 연습을 위한 AI 코치 |
| 놓친 순간을 다시 보고, 다음 연습을 바꿉니다 |
| 세 가지를 한 번에 봅니다 — 발표 자료 · 음성 · 영상 |
| 통합 분석으로 남는 것 (면접도 같은 구조라고 말로만) |
| 사용 흐름 — 준비 → 연습 → 리포트 → 다음 연습 |

> 삭제: 기존 19번 (면접용으로 17·18 반복), 21번 (기록이 쌓일수록)

## 03. 시연 — 1장

섹션 표지만. 실제 화면으로 진행.
여기서 예상 질문 · 기업 특화 질문 · 면접관 유형은 **화면으로만** 보여주고 언급하지 않음.

| 슬라이드 | 부제 |
|---|---|
| 섹션 표지 | |
| 연습이 끝나면, 리포트 한 장이 남습니다 | *"아까 그 9회·4회·3회, 여기서 나온 숫자입니다"* |
| ① 얼마나 더듬었는지, 얼마나 빨랐는지 | 말속도 · 추임새 · 침묵 |
