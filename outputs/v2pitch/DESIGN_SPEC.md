## 2. 글꼴 (Typography)

**Noto Sans KR + Noto Sans KR Black** 조합입니다.

웹 UI 폰트 스택이 `Pretendard Variable → Pretendard → Noto Sans KR`인데, **작업 PC에 Pretendard가 설치되어 있지 않아** 이전 덱들은 검수 화면과 실제 결과가 달랐습니다. Noto Sans KR은 그 스택의 공식 fallback이고 설치되어 있어 검수가 실물과 일치합니다.

> Pretendard로 바꾸려면: PowerPoint `홈 → 바꾸기 → 글꼴 바꾸기`에서 두 글꼴을 각각 한 번씩 교체하면 전체 반영됩니다.

| 단계 | 글꼴 | 크기 | 사용처 |
|---|---|---|---|
| Display | Black | 76–96pt | "잠시만요.", 섹션 커버 번호 |
| H1 | Black | 44–56pt | 큰 문장 슬라이드, 섹션 이름 |
| H2 | Black | 30–38pt | 콘텐츠 슬라이드 제목 |
| H3 | Black | 19–24pt | 카드 제목, 다이어그램 라벨 |
| Body | Regular | 13–15pt | 설명문 |
| Caption | Regular | 11–12pt | 보조 설명, 출처 |
| Eyebrow | Bold + 자간 1.6 | 10pt | 좌상단 섹션 라벨 |
| 큰 숫자 | Black | 76pt (+단위 22pt) | 지표 카드 |

행간은 제목 1.2, 본문 1.45–1.6으로 고정했습니다.

## 3. 레이아웃 & 시각화

### 그리드
- 좌우 여백 **1.0"**, 본문 폭 **11.33"**
- 헤더 고정: 눈썹 `y=0.73"` → 제목 `y=1.2"` → 구분선 `y=2.24"` → 본문 `y≥2.85"`

### 카드를 쓰지 않습니다 (중요)
채워진 카드와 테두리 박스는 **전부 제거**했습니다. 답답해 보이기 때문입니다. 구조를 만드는 요소는 세 가지뿐입니다.

1. **컬럼 상단 얇은 룰** — 두께 0.026"(≈2px). 브랜드 블루면 강조 컬럼, `#E4E6EE`면 일반 컬럼. 카드 역할을 이 선 하나가 대신합니다.
2. **행 사이 헤어라인** — 두께 0.014", 색 `#ECEEF4`. 리스트·단계 구분에만.
3. **여백** — 컬럼 간격을 0.42"~0.8"로 넉넉히 벌려 선이 없어도 묶여 보이게 했습니다.

예외는 두 곳뿐입니다.
- **기능 슬라이드의 캡처 자리** — 테두리 없는 옅은 면(`#F2F4F9`). 실제 스크린샷이 들어갈 영역이라 위치를 알려주는 용도이고, 캡처를 넣으면 사라집니다.
- **진행 인디케이터** — 우상단 6칸 점선. 장식이 아니라 위치 표시용입니다.

### 진행 레일 (신규)
우상단에 **6칸 인디케이터**를 넣어 지금 어느 섹션인지 항상 보이게 했습니다. 현재 섹션만 브랜드 블루, 나머지는 회색. 장식이 아니라 청중의 위치 파악용입니다.

## 4. 애니메이션 & 전환

**PowerPoint에 실제로 적용해 두었습니다.** 파일을 열고 F5만 누르면 바로 동작합니다.

### 슬라이드 전환 — 57장 전부
- **Fade 0.7초** (39장) — 기본. 튀지 않고 장면이 갈리는 느낌만 줍니다.
- **Morph 0.9초** (18장) — 앞 슬라이드와 레이아웃이 같은 경우. 향후 계획 01→02→03, 시연 01→02, 기능 카드 연속, Q&A 연속에서 숫자와 제목이 **제자리를 옮기듯** 움직입니다. 최신 웹사이트 스크롤 느낌에 가장 가까운 효과입니다.

### 등장 애니메이션 — 22장 / **발표 전체 클릭 7번**
전부 **Fade 0.5초**만 씁니다. 날아오기·튀기기 같은 효과는 쓰지 않았습니다.

**한 줄씩 나타나지 않습니다.** 슬라이드마다 원칙적으로 **한 번에 한 덩어리**만 등장합니다.

- 헤더(눈썹·제목·구분선·진행 레일)는 **애니메이션 없음** — 슬라이드 진입 즉시 표시
- 기본은 **1단계**: 본문 전체가 슬라이드 도착 0.2초 후 **동시에** 페이드인 (18장)
- 내레이션이 하나씩 짚어야 하는 **4장만 2~3단계**로 나눔 — 각 단계 안의 도형은 전부 동시 등장

| 슬라이드 | 단계 | 클릭 |
|---|---|---|
| #7 방금 발표 분석 | 3 (필러 → 공백 → 시선 이탈) | 2 |
| #12 지금까지의 연습 방법 | 2 (3열 비교 → 결론) | 1 |
| #17 세 가지를 한 번에 | 3 (입력 → AIVO → 출력) | 2 |
| #19 슬라이드 단위 연결 | 3 (전환 트랙 → 발화 트랙 → 결과) | 2 |

나머지 18장은 클릭 없이 자동으로 한 번 나타납니다. 즉 **발표 내내 애니메이션 때문에 눌러야 하는 클릭은 총 7번**뿐입니다.

> 단계를 더하거나 줄이려면 `steps.txt`를 고치고 `animate.ps1`을 다시 돌리면 됩니다. 개별 조정은 `애니메이션 → 애니메이션 창`에서 트리거를 클릭↔자동으로 바꾸세요.
